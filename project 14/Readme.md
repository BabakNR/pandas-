# Student Performance

## Overview
**Student Performance** is a Python project for predicting student performance based on the [Student Exam Scores Dataset](https://www.kaggle.com/datasets/spscientist/students-performance-in-exams).  
The model classifies students into **high performance** (average score ≥ 70) or not, using a Random Forest Classifier.

## Features
- Data cleaning and preprocessing
- Encoding categorical variables
- Feature engineering
- Outlier detection with interactive boxplots
- Exploratory Data Analysis (histograms, correlation heatmaps)
- Machine learning pipeline with scaling, training, and evaluation
- Model evaluation with classification report, confusion matrix, and feature importance
- Saving trained model and scaler for later use
